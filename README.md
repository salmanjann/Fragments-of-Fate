# Fragments of Fate 🌟

**Fragments of Fate** is a handcrafted 2D platformer where players navigate a magical world filled with enemies, traps, and collectible fragments that unveil the story. Built in Unity, the game blends responsive controls, enemy AI, and engaging level design.

## 🎮 Core Features

- **Player Mechanics**  
  Smooth movement, jumping, and combat mechanics designed for precision and responsiveness.

- **Enemy AI**  
  Intelligent enemies with patrol, chase, and attack behaviors to challenge the player.

- **Collectibles System**  
  Hidden fragments scattered across levels that unlock lore or game progress.

- **Tilemap-Based World**  
  Efficiently designed levels using Unity’s 2D Tilemap system for scalable content.

## 🛠️ Tools & Tech

- Unity (2D)
- C# Scripting
- Tilemap & Cinemachine
